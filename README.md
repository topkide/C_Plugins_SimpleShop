# SimpleShop

단일 서버용 GUI 상점 플러그인. (Paper **1.21.4** / Java 21 / Vault 필수)

## 빌드

```bash
./gradlew build
```

결과물: `build/libs/SimpleShop-1.0.0.jar` → 서버 `plugins/` 폴더에 넣으면 됩니다.
(윈도우는 `gradlew.bat build`)

셰이딩할 의존성이 없어 shadow 플러그인 없이 plain jar 그대로 사용합니다.
서버에 **Vault + 이코노미 플러그인**(EssentialsX 등)이 있어야 활성화됩니다.

## 명령어

| 명령어 | 설명 | 권한 |
|---|---|---|
| `/상점` | 상점 UI 열기 | `simpleshop.use` (기본 허용) |
| `/상점관리 설정` | 상점 편집 UI 열기 | `simpleshop.admin` (기본 OP) |
| `/상점관리 페이지 <번호>` | 상점 최대 페이지 설정 | `simpleshop.admin` |
| `/상점관리 리로드` | config.yml + shop.yml 리로드 | `simpleshop.admin` |

별칭: `/shop`, `/샵`, `/shopadmin`

## 사용법

### 관리자 (편집 UI)
- **1~4번 줄(36칸)**: 인벤토리에서 아이템을 집어 빈 칸에 놓으면 상품 등록
  (원본 아이템은 소모되지 않고 **복사 등록**됩니다)
- **클릭**: 상품 위치 이동 (빈 칸에 놓기 / 다른 상품 칸에 놓으면 자리 교환)
- **쉬프트+클릭**: 상품 상세설정 UI (구매/판매 가격)
- **Q키(버리기)**: 상품 제거
- 가격 버튼 클릭 → UI 닫힘 → **채팅으로 숫자 입력** → 설정 후 UI 자동 재오픈
- 가격에 **-1** 입력 시 해당 거래 비활성 → 구매 전용 / 판매 전용 상품 구현
- 상품 설정 UI에서 **ESC** → 상점 편집 UI로 복귀
- 등록 직후 상품은 구매/판매 모두 비활성(-1) 상태이므로 가격을 설정해야 거래 가능

### 유저 (/상점)
- **좌클릭**: 1개 구매 / **우클릭**: 1개 판매
- **쉬프트+좌클릭**: 64개 구매 / **쉬프트+우클릭**: 64개 판매 (수량 config 조절 가능)
- 가격은 **아이템 1개 기준**, 하단 가운데에 본인 보유 금액 표시

## 커스터마이징

`plugins/SimpleShop/config.yml` 에서 UI 제목, 버튼 아이템/이름/로어,
상품 로어, 모든 메시지를 수정할 수 있습니다. (한글 주석 포함)
수정 후 `/상점관리 리로드` 로 즉시 적용됩니다.

상점 데이터는 `plugins/SimpleShop/shop.yml` 에 편집 즉시 자동 저장됩니다.

## 구조 노트

- 상점 아이템은 Paper 의 버전 안전 직렬화(`serializeAsBytes`)로 저장되어
  커스텀 이름/로어/인챈트/NBT 가 그대로 보존됩니다.
- 내부적으로 상점 ID 를 들고 있어, 나중에 다중 상점으로 확장할 때
  데이터 마이그레이션 없이 확장 가능합니다.
